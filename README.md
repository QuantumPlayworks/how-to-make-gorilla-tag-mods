## 🧰 Requirements

* Gorilla Tag (Steam)
* BepInEx (installed in your game folder)
* Visual Studio (C#)

---

## 📥 Installation

1. Download this repo
2. Build the project in Visual Studio
3. Take the compiled `.dll` from:

   ```
   bin/Debug/
   ```
4. Put it into:

   ```
   Gorilla Tag/BepInEx/plugins/
   ```

---

## ▶️ Usage

* Press **P** → logs message
* Hold **Shift** → speed boost (example mod)

---
